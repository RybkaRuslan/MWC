# Husky Git Hooks

Этот проект использует Husky для автоматической проверки кода перед коммитами.

## Настроенные хуки

### pre-commit

- **Lint-staged**: Автоматически проверяет и исправляет код с помощью ESLint и Prettier
- **Type-check**: Проверяет типы TypeScript

### commit-msg

- Проверяет что сообщение коммита имеет правильную длину (1-50 символов)

## Как это работает

1. При попытке сделать коммит запускается `pre-commit` хук
2. ESLint проверяет и автоматически исправляет проблемы в коде
3. Prettier форматирует код согласно настройкам
4. TypeScript проверяет типы
5. Если все проверки прошли успешно - коммит создается
6. Если есть ошибки - коммит отменяется с сообщением об ошибке

## Команды для ручной проверки

```bash
# Проверить код ESLint-ом
npm run lint

# Исправить проблемы автоматически
npm run lint:fix

# Форматировать код
npm run format

# Проверить форматирование
npm run format:check

# Проверить типы
npm run type-check
```

## Обход хуков (не рекомендуется)

Если нужно срочно сделать коммит без проверок:

```bash
git commit --no-verify -m "срочный коммит"
```
